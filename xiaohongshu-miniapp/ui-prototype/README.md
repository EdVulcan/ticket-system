### 多商户内容边界（用户明确要求）

本原型的云门山名称、照片与文字仅为演示数据，不得复制为正式小程序的默认商户内容。正式页面须继续使用当前商户目录提供的 `store_name`、商品 `name/image_url/description/tags` 等字段及服务端商品规则；租户身份与范围仍由服务端会话确定。

- 商户名称用于导航栏；品牌图、头图、地域介绍等展示内容若当前目录没有对应配置，不得硬编码云门山或借用其他商户的内容，先省略再讨论必要配置。
- 景区、酒店、混合业态按真实商品类型与预约模式展示术语和入口，不能给纯酒店渲染入园、游玩日期或门票数量。
- 通用按钮和系统状态文案属于界面组件，商品宣传语、包含项目、日期/退款条件必须来自商品配置或规则快照，不从示例文案推导业务。
- 青蓝是当前演示的视觉主题，不构成其他商户必须采用云门山品牌或素材的要求。正式主题配置的范围待设计确认，当前不新增后台模型。
